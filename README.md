# Ansible Collection - kompetenztestde.testcenter

This repo contains the `kompetentestde.testcenter` Ansible Collection. It contains modules to work with the IQB
Testcenter and a role to install an instance.

## External requirements

All modules require the [requests](https://requests.readthedocs.io/en/latest/) Python library to be installed on the
host.

## Using this collection

Before using the Testcenter collection, you need to install the collection with the `ansible-galaxy` CLI:

```bash
ansible-galaxy collection install kompetenztestde.testcenter
```
